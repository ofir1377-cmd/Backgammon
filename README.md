# 🎲 שש-בש עם חברים

משחק שש-בש (Backgammon) אונליין לשני שחקנים, מותאם לטלפונים ניידים.
שחקן אחד פותח משחק ומקבל **קוד בן 4 ספרות**, החבר מקליד את הקוד באתר (או לוחץ על קישור ששותף בוואטסאפ) – ומשחקים, כל אחד מהטלפון שלו.

## מה יש במשחק
- חוקי שש-בש מלאים: הכאה ובר, כניסה מהבר, חובה לנצל את מקסימום הקוביות (ואת הקובייה הגבוהה אם רק אחת אפשרית), דאבל = 4 מהלכים, הוצאת כלים.
- הטלת פתיחה אוטומטית – מי שקיבל מספר גבוה יותר מתחיל.
- ביטול מהלכים בתוך התור לפני אישור "סיים תור".
- סימון כלים שאפשר להזיז (צהוב) ויעדים חוקיים (ירוק).
- כל שחקן רואה את הלוח מהצד שלו (הבית שלו תמיד למטה מימין).
- ניקוד מצטבר בין משחקים: ניצחון = 1, מארס (גמון) = 2, טורקי מארס (בקגמון) = 3.
- חזרה אוטומטית למשחק אחרי רענון / ניתוק רשת.
- שיתוף קישור הזמנה (Share / WhatsApp).

## הרצה מקומית
דרוש Node.js 18 ומעלה.

```bash
npm install
npm start
```

פתחו את `http://localhost:3000`. כדי לשחק מטלפון באותה רשת Wi‑Fi – גלשו לכתובת ה-IP של המחשב, למשל `http://192.168.1.20:3000`.

בדיקות: `npm test`

## העלאה לאינטרנט (חינם) – Render
1. היכנסו ל-[render.com](https://render.com) והתחברו עם GitHub.
2. **New → Blueprint** ובחרו את הריפו הזה (הקובץ `render.yaml` כבר מוגדר).
   לחלופין **New → Web Service**: Build `npm install`, Start `npm start`.
3. אחרי כמה דקות תקבלו כתובת כמו `https://backgammon-xxxx.onrender.com` – שלחו אותה לחברים.

> בתוכנית החינמית השרת "נרדם" אחרי זמן ללא שימוש, והכניסה הראשונה לוקחת כחצי דקה.
> המשחקים נשמרים בזיכרון השרת, כך שהפעלה מחדש של השרת מוחקת משחקים פעילים.

כל שירות שתומך ב-Node.js ו-WebSockets יעבוד גם הוא (Railway, Fly.io וכו').

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `src/game.js` | מנוע החוקים: לוח, מהלכים חוקיים, הוצאה, ניקוד |
| `src/room.js` | חדר משחק: שחקנים, תורות, קוביות, ביטול, משחק חוזר |
| `server.js` | שרת Express + Socket.IO, יצירת קודים וחיבור שחקנים |
| `public/` | צד הלקוח: מסכים, ציור הלוח ב-SVG ושליטה במגע |
| `test/` | בדיקות לחוקים ולזרימת המשחק |

השרת הוא הסמכות היחידה על מצב המשחק – הלקוח רק מציג ושולח בקשות, ולכן אי אפשר "לרמות" מהדפדפן.
